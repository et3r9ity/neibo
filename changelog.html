Alpha 3.0.0 changelog

Every screen redrawn in glass, a whole new tab with 1492 places
in Riga, and events that read like Reels.

7 September 2026 · Neibo alpha test

⚠️ Update Expo Go first

Alpha 3.0.0 runs on a brand-new Expo runtime (SDK 57). Expo Go only opens projects built for the version it ships with, so an older Expo Go will not see this update at all — you would keep opening 2.6.0 and think nothing happened.

If you see "Project is incompatible with this version of Expo Go", that is the same thing from the other side: update Expo Go and open Neibo again.

Update · App Store Update · Google Play

🧊 A completely new look

NEWGlass, not panels. Map controls, the tab bar and the sheets are now translucent glass that picks up the map underneath, instead of solid cream-coloured panels. On iOS 26 it is the real system material, so it bends and blurs whatever is behind it.

NEWOne accent instead of many. Text and controls dropped to a single near-black ink, so colour on screen now means something — a category, an alert, a live event — rather than decoration.

NEWA dock that follows the screen. The bottom bar now carries a contextual button on the left that changes with the screen you are on: how many events are nearby on the map, list-or-map in Where to go. Selected tabs fill in, the rest stay outlines.

If you tested in August, this is the part that never reached you. The redesign was finished four weeks ago, but a delivery setting kept it from being published. That is fixed — it is in this release.

🍸 Where to go — a new tab

NEW1492 places in Riga. The Events tab became Where to go: restaurants, cafés, bars, pubs, museums, clubs, theatres and stages, imported from OpenStreetMap.

NEWOpen right now. Every place carries its opening hours, so the list can tell you what is open at this moment and when the rest closes — and you can filter down to just the open ones.

NEWFilters that count first. The filters page shows how many places match each option before you apply it, so you never tap into an empty list.

NEWList or map, one button. Switch with the button at the bottom left. On the map, places group into clusters and open as cards; in the list they are sorted by distance from you.

NEWA page per place. Tap any place for its full page: hours for the week, address, distance, what it offers, and a route button.

📱 Events read like Reels

NEWFull-screen cards. Tapping a pin opens the photo full-screen with the street, the distance and the report itself over it. Pull down to dismiss.

NEWSwipe through the neighbourhood. Swipe left or right to move between everything nearby without going back to the map.

NEWComments inside the card. No separate screen any more. A row of quick reactions sits above the input, and they are ordinary system emoji now — the same ones your keyboard types.

NEWDouble-tap to like. On the photo, or on the heart. The heart fills in red the way you would expect.

📍 Nearby, on the map

NEWYour zone, at a glance. The button at the bottom left of the map shows how many events are inside your zone and opens the list of them.

NEWRadius is yours. 500 m, 1, 2 or 5 km — and the circle drawn on the map shows exactly what counts as nearby, including for alerts.

🎚️ Feed filters, rebuilt

NEWSame filters as Where to go. One Filters button with a badge showing how many are active, and a page where every event type shows its own count.

FIXThe Neighbours / News switch stops drifting. The sliding thumb used to sit off-centre on the longer label. It now measures each side properly.

⚙️ Under the hood

Three SDK versions in one jump. Neibo moved from Expo SDK 54 to 57, React Native from 0.81 to 0.86, and the map was rewritten onto React Native's new rendering architecture. It was done in three separate steps so any breakage could be traced to one of them.

None of this should be visible to you, which is the point — and it is why Expo Go has to be updated: the runtime this build asks for is exposdk:57.0.0, and only the newest Expo Go provides it.

🔧 Fixed along the way

FIXSwiping through event cards no longer freezes — every swipe used to kick off a storm of live-update traffic.

FIXThe Where to go map no longer crashes when you zoom out and back in.

FIXIcons no longer show up as question marks.

FIXThe Nearby button keeps its glass — leaving the map and coming back left it fully transparent.

FIXPulling an event card down closes it from anywhere on the card, and scrolling inside it no longer fights the swipe.

FIXMap clusters no longer jump when your location updates.

FIXOpenStreetMap attribution added to the Where to go map, as its licence requires.

⚠️ Known issues

Push notifications still do not arrive in Expo Go. Alerts work inside the app, but system notifications need a standalone build — a separate release, not a setting we can flip.

Where to go covers Riga only. The catalogue is imported city by city; the rest of Latvia is next.

The Latvian interface is incomplete. The strings exist; the translation is being filled in.

The Live filter is off in the News layer. Parsed news has no "happening now" information, so the filter would always come back empty. It stays available for neighbour reports.
